# Source of the Tears of Steel example

- **Title:** Tears of Steel (2012), a live-action science-fiction short film by the Blender Foundation (Project
  Mango), 12:14
- **Page:** https://mango.blender.org/ (and https://studio.blender.org/projects/tears-of-steel/)
- **Video:** https://download.blender.org/demo/movies/ToS/tears_of_steel_720p.mov (1280×534, H.264 with MP3 audio
  in a QuickTime file, 372 MB). The captions were made from this file and the demo streams it, so the timing needs
  no offset.
- **Captions:** made on 2026-10-28 with the [models in ../README.md](../README.md#models).

## The video is not included

`*.mov` is git-ignored. The demo streams the video from Blender: `npm run demo`, then open
http://localhost:5173/examples/demo/?clip=tears-of-steel. To run the pipeline yourself, download the file above to
`examples/media/tears-of-steel.mov` and use the command in [../README.md](../README.md#commands).
