# Source of the Cosmos Laundromat example

- **Title:** Cosmos Laundromat: First Cycle (2015), an animated short film by the Blender Institute (Project
  Gooseberry), 12:11
- **Page:** https://gooseberry.blender.org/ (and https://studio.blender.org/projects/cosmos-laundromat/)
- **Video:** https://download.blender.org/gooseberry/movies/cosmos_laundromat_720p.mp4 (1280×536, H.264 with AAC
  audio, 294 MB). The captions were made from this file and the demo streams it, so the timing needs no offset.
- **Captions:** made on 2026-10-28 with the [models in ../README.md](../README.md#models).

## The video is not included

`*.mp4` is git-ignored. The demo streams the video from Blender: `npm run demo`, then open
http://localhost:5173/examples/demo/?clip=cosmos-laundromat. To run the pipeline yourself, download the file above
to `examples/media/cosmos-laundromat.mp4` and use the command in [../README.md](../README.md#commands).
