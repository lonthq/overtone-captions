Overtone demo

The player loads examples/output/nasa/nasa-dutton.overtone.json, a real run of the pipeline on a NASA interview (see examples/output/README.md). The video streams from NASA and is not part of this repository. The players load examples/output/tears-of-steel/, a real run of the pipeline on Tears of Steel (2012), a live-action science-fiction short. The video streams from Blender (download.blender.org) and is not part of this repository. Film: (CC) Blender Foundation | mango.blender.org, CC BY 3.0. The players load examples/output/elephants-dream/, a real run of the pipeline on Elephants Dream (2006), an animated short with two main characters, Proog and Emo. The video streams from Blender (download.blender.org) and is not part of this repository. Film: (c) copyright 2006, Blender Foundation / Netherlands Media Art Institute / www.elephantsdream.org, CC BY 2.5. The players load examples/output/cosmos-laundromat/, a real run of the pipeline on Cosmos Laundromat (2015), an animated short in which a sheep named Franck meets a salesman named Victor; the dialogue starts at 2:20. The video streams from Blender (download.blender.org) and is not part of this repository. Film: (CC) Blender Foundation | gooseberry.blender.org, CC BY 3.0. The CC button (or press C after clicking a player) cycles off → styled → plain → off: styled shows the word highlights, plain shows the same captions without them, and your choice is remembered. See also the style gallery of every style pack.
