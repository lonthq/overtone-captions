Why Overtone

Most captions are cut once, for one screen, by filling each line to a length limit. Turn the video vertical and that cut falls apart. Overtone stores every word once, with its time and speaker, and cuts the lines for each screen shape by reading rules. A line avoids ending on “the” or “of”. Names and numbers stay together. Each speaker gets their own caption, and pauses show as breaks. Bring your own SRT or WebVTT, or let the CLI transcribe your media: a transcription model writes the text, speech engines time each word, and an LLM editor fixes names and terms. The LLM never sets timestamps.

On three English clips (21 minutes, 16:9 cuts), 0.3% of Overtone’s breaks end on a word like “the”, “of” or “and” with no pause after it. Filling lines to the limit gives 29%, ElevenLabs’ SRT export 16%. Overtone shows all 47 pauses of 0.5–1.5 s as a break; the other two show 28% and 72%. These are rule checks, not reader judgments. Details in the caption benchmark.

Format overtone-format

One .overtone.json file holds each word once, with its time, speaker and semantic classes, plus a line cut per screen shape. Comes with a JSON Schema, a validator and exporters to WebVTT, SRT and plain text. No runtime dependencies. Runs in Node and the browser.

{ "text": "Peacocks.",
  "start": 30.39, "end": 31.07,
  "classes": ["key"] }

Player videojs-overtone

A video.js 8.5+ plugin. It shows the line cut closest to the shape of the picture and switches live on resize. The CC button or the C key cycles off → styled → plain. Pick one of %%PACK_COUNT%% style packs or write your own CSS.

player.overtone({
  src: 'talk.overtone.json',
  theme: 'social',
});
Player docs →

CLI overtone-captions

Re-cuts the SRT or WebVTT you already have, offline and with no keys. Or turns audio and video into captions: text from a transcription model (OpenAI, Azure OpenAI or ElevenLabs), word times and speakers from Azure AI Speech (or ElevenLabs or OpenAI), and an LLM editor (OpenAI, Azure OpenAI or Anthropic). Code checks the structure of every edit. --local runs it all on your machine. Writes JSON, WebVTT, SRT and a transcript, or an MP4 with the styled captions burned in.

npx overtone-captions recut talk.srt

overtone transcribe talk.mp4 \
  --context "Panel about cycling"

Contribute

Each task is small, has its own guide and needs no knowledge of the pipeline.

Add a language

A language pack is a set of word lists written by native speakers. They tell the line cutter which words belong together and where a line may end.

A caption theme for the player: one CSS file and a short pack.json. No JavaScript. The tests tell you when it is ready.
